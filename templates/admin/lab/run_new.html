How to post a benchmark result

  1. Run the test through Hermes as usual: hapitech-model-tester sends the prompt to the target profile while capture_telemetry.py records the hardware.
  2. When you've approved the result, hapitech-benchmark writes the JSONL record (same format as before).
  3. Upload that file here. The test ID must match a prompt, and the model must match a model ID (close names like Qwen3.8-27B-UD-IQ3_XXS are matched automatically).
  4. Open the draft and check pass/fail, tokens per second and time to first token. Add a one-line summary in plain English.
  5. Built something (like the game from prompts 06/07)? Attach the HTML on the run page. It plays in a sandbox.
  6. Press Publish. It appears on /lab and in AI news as "HapiTech Lab".
  7. Wrong numbers? Withdraw hides it straight away and keeps the record.
